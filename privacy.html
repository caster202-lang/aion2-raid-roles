개인정보처리방침

시행일: 2026년 11월 22일

1. 수집하는 정보

이 사이트는 회원 가입이 없고, 운영자 서버로 개인정보를 수집·저장하지 않습니다.

2. 브라우저에 저장되는 정보

입력한 공대원 이름·직업, 본부 조합 참가자, 화면 설정(라이트·다크), 직접 고친 직업 기억, 입력한 AI API 키는 이용자의 브라우저 저장소(localStorage)에만 저장됩니다. "키를 저장하지 않기"를 고르면 API 키는 창을 닫을 때 지워지는 저장소(sessionStorage)에만 둡니다. 브라우저의 사이트 데이터 삭제로 언제든 지울 수 있습니다.

3. 외부로 전송되는 정보

"캡처 바로 읽기"를 쓰는 경우에만, 붙여넣은 캡처 이미지와 이용자가 입력한 API 키가 이용자가 고른 회사(Google Gemini 또는 Anthropic Claude)로 전송됩니다. 전송된 정보의 처리는 해당 회사의 개인정보처리방침을 따릅니다.

4. 쿠키와 광고

이 사이트는 Google AdSense 등 제3자 광고를 게재할 수 있습니다. 광고 제공업체(Google 포함)는 쿠키를 사용해 이용자의 이 사이트 및 다른 사이트 방문 기록을 바탕으로 광고를 표시할 수 있습니다. 이용자는 Google 광고 설정(adssettings.google.com)에서 맞춤 광고를 끌 수 있고, 브라우저 설정에서 쿠키를 거부할 수 있습니다.
