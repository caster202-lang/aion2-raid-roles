# 본부 조합 (본캐·부캐 로테이션) 설계 — 2026-11-18

동작 분석은 `2026-11-18-alt-rotation-analysis.md`. 사용자 결정:
- 위치: 위쪽 성역 버튼 줄에 "본부 조합" 버튼 추가(같은 페이지).
- 배정: 분석한 방식 그대로(앞 판부터 채움, 모자라면 경고만).
- 직업 입력: 드롭다운(기존 공대원 입력과 같음).
- 연결: 판마다 "명단에 넣기" → 1파티 → 1~5번 줄, 2파티 → 6~10번 줄에 이름(서버 제외)·직업을 채우고 마지막으로 쓰던 무스펠/비탄 화면으로 돌아간다. 외부인원 자리는 비운다. 1파티 모드면 1~5번 줄만.

## 화면
- `st.raid === 'hq'`이면 기존 입력·기믹 영역(`#raidView`)을 숨기고 `#hqView`를 보인다. `st.prevRaid`에 마지막 무스펠/비탄을 기억.
- 기본 설정: 성역 기준(루드라 200k / 바고트 400k / 무스펠 보통 550k / 무스펠 어려움 600k / 직접 입력), 파티 수 1·2, 참가자당 부캐 수 0~5(기본 2).
- 참가자: 닉네임[서버] 칸, 삭제, 본캐·부캐 칸마다 직업 드롭다운·전투력. 부캐는 "서버 분리" 체크 시 부캐 서버 칸.
- 배정 조건: 파티당 최소 탱커·서폿(0~3, 기본 1), 파티 최소 평균 전투력, 본캐 몰아주기, 직업 분포.
- 결과: 게임별 카드(게임 복사·명단에 넣기), 파티별 목록·경고·파티 복사, 전체 복사.

## 계산 (화면과 무관한 함수, 자체 시험 대상)
- `hqRole(job)`: 수호성·검성 tank / 치유성·호법성 support / 나머지 dealer.
- `parsePower(s)`: 쉼표·공백 제거, `k`면 ×1000, 1만 미만 숫자는 ×1000, 아니면 그대로. 못 읽으면 0.
- `fmtPower(n)`: 1000 단위면 `600k`, 아니면 소수 한 자리 `612.5k`, 0이면 빈 글.
- `splitNick(s)`: `이름[서버]`·`이름(서버)`를 이름·서버로 나눔.
- `buildGames(people, opt)`: 분석 문서 3장 순서 그대로(최대 30판).
- `hqPartyText` / `hqGameText` / `hqAllText`: `[게임1 파티1] 평균 610k` + `1. 이름[서버] 직업(역할/본|부) 전투력`, 외부인원은 `n. 외부인원 -(딜러/외부)`.
- `gameRows(game)`: 10줄 `{name, job}`(외부인원은 빈 칸).

## 저장
- localStorage `aion2-hq-v1`(설정·참가자). 결과는 저장하지 않음(조합 생성 때마다 다시 계산).

## 한 번에 붙여넣기 (2026-11-19, 사용자 양식)
- 한 줄에 캐릭터 1개 `닉네임[서버] 직업 전투력`. 참가자마다 첫 줄 본캐, 아래 줄 부캐, 참가자 사이는 빈 줄.
- 직업은 줄임말·첫 글자 허용, 전투력 1045 → 1045k. 닉네임이나 직업을 못 읽은 줄은 빼고 몇 번째 줄인지 알림.
- 부캐 수는 붙여넣은 명단의 최대 부캐 수(최대 5)로 맞춤. 기존 참가자가 있으면 확인 후 바꿈.
- 부캐는 자기 닉네임[서버]를 가짐(비우면 본캐 닉네임). 결과·복사·명단에 넣기는 캐릭터 닉네임으로. "서버 분리" 체크는 부캐 닉네임 칸으로 대체.
- "지금 명단 복사"로 현재 참가자를 같은 양식으로 꺼낼 수 있음.
