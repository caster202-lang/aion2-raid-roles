# 성역 본캐·부캐 로테이션 조합 — 동작 분석 (2026-11-18)

참가자마다 본캐 1개 + 부캐 N개(기본 2개)를 받아, 성역을 여러 판(게임) 도는 동안 모든 캐릭터가 한 번씩 들어가도록 파티를 짜는 방식이다.

## 1. 입력

| 항목 | 내용 |
|---|---|
| 성역 기준 | 루드라 200k · 바고트 400k · 무스펠 보통 550k · 무스펠 어려움 600k · 직접 입력 → "파티 최소 평균 전투력" 값으로 들어감 |
| 파티 수 | 1파티(5명) 또는 2파티(10명) |
| 참가자당 부캐 수 | 0~5 (기본 2 → 1인 3캐릭) |
| 참가자 | 닉네임[서버] · 캐릭터마다 직업 · 전투력. 부캐는 본캐 서버를 따르고 "서버 분리"를 체크하면 따로 적음 |
| 배정 조건 | 파티당 최소 탱커(0~3, 기본 1) · 파티당 최소 서폿(0~3, 기본 1) · 파티 최소 평균 전투력 · "본캐 한 파티에 몰아주기" 체크 |

- 직업 줄임말: 수호/탱/탱커→수호성, 치유/힐/힐러→치유성, 호법/찬터→호법성, 마도/마성→마도성, 정령→정령성, 격투/권→권성, 검→검성, 궁→궁성, 살→살성.
- 전투력: `550`처럼 1만 미만이면 ×1000(=550k), `550k`, 쉼표 허용.
- 입력값은 브라우저 localStorage에 저장.

## 2. 역할 구분

- 탱커: 수호성, 검성
- 서폿: 치유성, 호법성
- 딜러: 궁성, 살성, 마도성, 정령성, 권성

## 3. 배정 순서

남은 캐릭터가 없을 때까지(최대 30판) 아래를 반복한다. 한 판 = 파티 수 × 5자리.

### 3-1. 이번 판에 들어갈 캐릭터 고르기 (한 사람당 1캐릭)
1. 남은 캐릭터를 참가자별로 묶는다.
2. 참가자 우선순위 점수 = (남은 캐릭 중 탱커가 있으면 +2) + (서폿이 있으면 +2) + (가장 높은 전투력 ÷ 100만; 부캐는 ×0.9로 계산).
   점수 높은 순으로 자리 수만큼 사람을 뽑는다.
3. 뽑힌 사람의 캐릭터 중 하나를 고른다.
   - 기본: 본캐 먼저, 본캐를 이미 썼으면 전투력 높은 부캐.
   - 이번 판 탱커 수가 파티 수보다 적으면 → 그 사람의 탱커 캐릭을 우선.
   - 아니고 서폿 수가 파티 수보다 적으면 → 서폿 캐릭을 우선.
   - (주의: 이 단계의 탱·서폿 목표는 "파티당 1명"으로 고정이고, 최소 탱커·서폿 설정값은 여기서 쓰이지 않는다.)

### 3-2. 파티 나누기
1. 탱커를 파티마다 최소 탱커 수만큼 먼저 넣는다.
2. 서폿을 파티마다 최소 서폿 수만큼 넣는다.
3. 나머지를 전투력 높은 순으로, 인원이 가장 적은 파티(같으면 평균 전투력이 낮은 파티)에 넣어 평균을 맞춘다.
4. "본캐 몰아주기"를 켜면: 나머지 중 본캐를 1파티부터 채우고, 부캐는 인원 적은·평균 낮은 파티로 보낸다.
5. 빈자리는 "외부인원"으로 채운다.

### 3-3. 경고
파티마다 아래를 확인해 "주의:"로 표시한다(배정을 막지는 않음).
- 탱커 수 < 최소 탱커 → `탱커 x/최소`
- 서폿 수 < 최소 서폿 → `서폿 x/최소`
- 평균 전투력(외부인원 제외) < 기준 → `평균 전투력 X < 기준`

### 3-4. 다음 판
이번 판에 쓴 캐릭터를 빼고 3-1로 돌아간다.

## 4. 결과·복사 형식

게임별 → 파티별로 표시하고, 파티 복사 · 게임 복사 · 전체 복사가 있다.

```
[게임1 파티1] 평균 610k
1. 가가[시엘] 수호성(탱커/본) 650k
2. 나나[시엘] 치유성(서폿/부) 610k
...
```

## 5. 동작에서 확인된 특징

- 참가자 10명·부캐 2개·2파티면 판마다 10명이 1캐릭씩 들어가 3판이 나온다. 참가자가 10명보다 적으면 매 판 빈자리가 외부인원이 된다.
- 앞 판부터 한 판씩 차례로 채운다. 탱·서폿은 그 판 안에서만 맞추고, 뒤 판에 탱·서폿 캐릭이 남는지는 따지지 않는다. 판끼리 평균 전투력을 맞추는 계산도 없다.
- 평균 전투력 기준은 경고에만 쓰이고, 고르는 단계에는 반영되지 않는다.
- 한 판 안에서 같은 사람의 캐릭터가 둘 들어가는 일은 없다.
- 기믹 자리(드리블·신호등·쐐기 등) 배정은 하지 않는다.
