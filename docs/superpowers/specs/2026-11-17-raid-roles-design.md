# 무스펠 성역 역할 배분 사이트 — 설계

작성일: 2026-11-17

## 목적

아이온2 무스펠 성역(10인)에서 공대장이 역할을 채팅창에 직접 타이핑하는 불편을 없앤다.
공대원 10명을 입력하면 1네임드 드리블과 2네임드 신호등 자리를 자동으로 배정하고,
파티별 한 줄 문구를 복사해 게임 채팅창에 붙여넣을 수 있게 한다.

## 범위

넣는 것: 10명 입력, 깍두기 선정, 1네임드 드리블 배정, 2네임드 신호등 배정,
직접 바꾸기(깍두기·드리블 담당·2네임드 자리), 배치도, 파티별 복사, 브라우저 저장.

넣지 않는 것: 캐릭터 검색, 본·부캐 순환 편성, 페이즈별 패턴 안내, 로그인, 서버.

## 만드는 방식

- 파일 하나: `aion2-raid-roles/index.html` (HTML + CSS + JavaScript, 외부 라이브러리 없음).
- 서버 없이 브라우저에서만 동작한다. 더블클릭으로 열리고, 나중에 정적 호스팅에 그대로 올린다.
- 먼저 내 컴퓨터에서 확인하고, 올릴 곳은 그 뒤에 정한다.
- 파일 안에서 배정 계산(화면과 무관한 순수 함수)과 화면 그리기를 나눈다.

## 1. 입력

- 10줄. 1~5번 줄이 1파티, 6~10번 줄이 2파티. 파티는 줄 위치로 고정된다.
- 줄마다: 이름(글자), 직업(선택), "2줄 가능"(체크).
- 직업 9종: 수호성, 검성, 살성, 권성, 궁성, 마도성, 정령성, 치유성, 호법성. 고르지 않은 상태도 허용한다.
- "2줄 가능"은 파티별 2번·4번 줄이 기본으로 체크되어 있다(2026-11-17 추가). 체크를 바꾸지 않고
  5번이 깍두기면 1~4번이 그대로 1파티 12·11·9·7시, 2파티 6·5·3·1시에 들어간다.
- 한 파티의 다섯 이름이 모두 채워져야 그 파티의 배정과 복사가 켜진다.
  모자라면 "N명 더 입력 필요"를 보여준다. 두 파티는 서로 독립이다.

## 2. 깍두기 (파티당 1명)

자동 선택 순서:

1. 그 파티의 치유성. 여러 명이면 2줄 미체크인 치유성을 먼저, 그 안에서는 입력 순서가 빠른 사람.
2. 치유성이 없으면 2줄 미체크 인원 중 입력 순서가 가장 늦은 사람.
3. 전원이 2줄 체크면 마지막 줄 사람.

공대장이 파티별로 다른 사람을 직접 고를 수 있다. 직접 고른 깍두기는 "자동 배정으로 되돌리기"나
"초기화"를 누를 때까지 유지된다.

깍두기를 뺀 4명이 입력 순서대로 그 파티의 1~4번이 된다. 깍두기는 1·2네임드 모두 같은 사람이다.

## 3. 1네임드 드리블

| 파티 | 조 | 경로 | 복사 표기 |
|---|---|---|---|
| 1파티 | 1,2번 | 3시 → 3시 | `3->3` |
| 1파티 | 3,4번 | 9시 → 12시 | `9->12` |
| 2파티 | 1,2번 | 12시 → 9시 | `12->9` |
| 2파티 | 3,4번 | 6시 → 6시 | `6->6` |

- 조마다 드리블 담당 1명, 나머지 1명은 보조.
- 담당 자동 선택: 궁성 → 마도성 → 정령성 → 그 외. 같은 순위면 입력 순서가 빠른 사람.
- 공대장이 조별로 담당을 바꿀 수 있다.

## 4. 2네임드 신호등

| 파티 | 1줄 자리 (파랑) | 2줄 자리 (빨강) | 복사 순서 |
|---|---|---|---|
| 1파티 | 12시, 9시 | 11시, 7시 | 12시, 11시, 9시, 7시 |
| 2파티 | 6시, 3시 | 5시, 1시 | 6시, 5시, 3시, 1시 |

(2026-11-17 수정: 2파티는 6시부터 시작한다. 1파티가 12시에서 시계 반대 방향으로 가듯 2파티는 6시에서 시계 반대 방향으로 간다.)

자동 배정:

1. 파티 4명 중 2줄 가능 체크자를 입력 순서대로 2줄 자리에 넣는다(1파티 11시 → 7시, 2파티 5시 → 1시).
2. 체크자가 2명보다 많으면 넘치는 사람은 1줄 자리로 간다.
3. 체크자가 2명보다 적으면 남은 2줄 자리를 체크하지 않은 사람(입력 순서 빠른 순)으로 채우고
   "N파티: 2줄 가능 인원이 부족해 일반 인원을 배정했습니다"를 보여준다.
4. 나머지를 입력 순서대로 1줄 자리에 넣는다(1파티 12시 → 9시, 2파티 6시 → 3시).

직접 바꾸기: 같은 파티 안에서 두 사람을 차례로 누르면 자리가 서로 바뀐다.

## 5. 직접 바꾼 값의 유지 규칙

- 한 파티의 이름·직업·2줄 체크·깍두기 중 하나라도 바뀌면, 그 파티의 드리블 담당과
  2네임드 자리는 자동 배정으로 다시 계산된다(직접 바꾼 값은 버린다).
- "자동 배정으로 되돌리기": 깍두기·드리블 담당·2네임드 자리를 모두 자동 값으로 돌린다. 입력은 남긴다.
- "초기화": 입력과 직접 바꾼 값을 모두 지운다.

## 6. 복사

- 탭 두 개: "1네임드 드리블", "2네임드 신호등". 탭마다 "1파티 복사", "2파티 복사" 버튼.
- 버튼을 누르면 그 파티 한 줄이 클립보드에 들어가고 버튼 글자가 잠깐 "복사 완료"로 바뀐다.
- 문구(2026-11-17 시인성 수정: 머리말을 붙이고 칸을 띄워 ` / `로 구분):

| 버튼 | 문구 |
|---|---|
| 1네임드 1파티 | `[1넴] 3시->3시 가가 / 9시->12시 다다` |
| 1네임드 2파티 | `[1넴] 12시->9시 바바 / 6시->6시 아아` |
| 2네임드 1파티 | `[2넴] 12시 가가 / 11시 나나 / 9시 다다 / 7시 라라 / 깍두기 마마` |
| 2네임드 2파티 | `[2넴] 6시 사사 / 5시 바바 / 3시 자자 / 1시 아아 / 깍두기 차차` |

- 1네임드 줄에는 드리블 담당만 들어간다(보조와 깍두기는 적지 않는다).

## 7. 저장

- 입력과 직접 바꾼 값을 바뀔 때마다 그 브라우저의 localStorage에 저장하고, 열 때 불러온다.
- 저장을 쓸 수 없는 환경(사생활 보호 창 등)에서도 화면은 정상 동작한다.

## 8. 배치도

- 탭마다 그림 한 장(SVG). 입력·배정이 바뀌면 바로 다시 그린다.
- 1네임드: 보스를 가운데 두고 네 경로를 화살표로 그리고 경로마다 담당 이름을 적는다. 1파티 빨강, 2파티 초록.
- 2네임드: 여덟 자리에 이름을 적는다. 2줄 자리 빨강, 1줄 자리 파랑.
- 색만으로 구분하지 않도록 자리마다 "N시" 글자를 함께 적는다.

## 9. 확인 방법

- `index.html?selftest=1`로 열면 배정 계산을 시험 입력으로 돌려 통과/실패를 화면에 보여준다.
  - 기본 경우: 위 6번 표의 네 문구가 글자 단위로 같은지.
  - 치유성이 없는 파티, 치유성이 둘인 파티, 전원 2줄 체크인 파티의 깍두기.
  - 2줄 체크가 0명·1명·3명인 파티의 신호등 자리와 안내 문구.
  - 원거리가 없는 조, 원거리가 둘인 조의 드리블 담당.
  - 깍두기를 직접 바꿨을 때 1~4번과 두 네임드 배정이 따라 바뀌는지.
- 브라우저에서 직접: 복사한 문구 붙여넣기, 닫았다 열어 저장 확인, 자리 바꾼 뒤 그림·문구 동시 변경 확인.

# 추가: 비탄의 설원 (2026-11-17 결정)

## 구조

- 맨 위에 성역 탭 두 개: "무스펠의 성배", "비탄의 설원". 공대원 입력 10줄(이름·직업)은 두 성역이 같이 쓴다.
- "2줄", "깍두기" 칸은 무스펠 탭에서만 보인다.
- 비탄의 설원 안의 탭: "얼음쐐기", "파도패턴".
- 이름 10개가 모두 있어야 비탄의 설원 배정과 복사가 켜진다.

## 얼음쐐기 (2네임드)

| 자리 | 맡는 직업 |
|---|---|
| 내부 4명: 3·6·9·12시 | 수호성, 검성, 살성, 권성, 호법성 |
| 외부 4명: 3·6·9·12시 | 궁성, 마도성, 정령성 |
| 서브 2명 | 치유성 |

- 외부는 2-2(50%)에서 같은 사람이 한 시간 앞 자리(2·5·8·11시)로 옮긴다. 사이트는 2-1 자리만 배정하고 2-2 자리는 적지 않는다(화면에 안내 문구만 둔다).
- 자동 배정:
  1. 내부 직업을 입력 순서대로 내부 3·6·9·12시에, 외부 직업을 입력 순서대로 외부 3·6·9·12시에 넣는다.
  2. 넘친 사람, 직업 미선택 인원, 치유성을 남은 사람으로 모은다(치유성은 맨 뒤).
  3. 내부·외부에 빈자리가 있으면 남은 사람을 앞에서부터 채우고 "내부(외부) 인원이 부족해 다른 직업을 배정했습니다"를 보여준다.
  4. 마지막까지 남은 2명이 서브.
- 직접 바꾸기: 두 사람을 차례로 누르면 자리(내부·외부·서브 어디든)가 서로 바뀐다. 이름·직업이 바뀌면 자동 배정으로 다시 계산한다.
- 복사: "내부 복사", "외부 복사"
  - `[쐐기] 내부 3시 가가 / 6시 바바 / 9시 다다 / 12시 사사`
  - `[쐐기] 외부 3시 나나 / 6시 라라 / 9시 아아 / 12시 자자`

## 파도패턴

- 구역 네 개: 1~2시, 4~5시, 7~8시, 10~11시. 구역별 인원은 +/−로 정하고, "1-4-1-4", "3-3-3-1" 버튼으로 한 번에 고른다. 기본은 1-4-1-4.
- 사람은 입력 순서대로 구역 순서(1~2 → 4~5 → 7~8 → 10~11)에 채운다. 1-4-1-4면 1파티가 1~2시·4~5시, 2파티가 7~8시·10~11시가 된다.
- 인원 합이 10이어야 복사가 켜진다. 아니면 "구역 인원 합계 N/10"을 보여준다.
- 직접 바꾸기: 두 사람을 차례로 누르면 서로 바뀐다. 이름·직업·구역 인원이 바뀌면 다시 계산한다.
- 복사: "파도패턴 복사" 하나. 0명 구역은 적지 않는다.
  - `[파도] 1~2시 가가 / 4~5시 나나, 다다, 라라, 마마 / 7~8시 바바 / 10~11시 사사, 아아, 자자, 차차`

## 배치도

- 얼음쐐기: 안쪽 원 네 점(내부), 바깥 원 네 점(외부)에 이름.
- 파도패턴: 네 사분면에 구역 이름과 사람 이름.

## 시험

- 기본 입력(내부 직업 5·외부 3·치유 1·호법 1 등)으로 내부·외부·서브와 두 복사 문구.
- 치유성 0명, 치유성 3명, 외부 직업 부족(안내 문구), 직업 미선택.
- 직접 바꾸기 후 문구.
- 파도: 1-4-1-4, 3-3-3-1 문구, 합계가 10이 아닐 때 복사 꺼짐, 0명 구역 생략, 바꾸기.

# 추가: 명단 붙여넣기 (2026-11-17 결정)

캡처에서 바로 글자를 읽는 방식은 브라우저 무료 인식으로는 쓸 수 없는 정확도라, AI 앱을 거치는 방식으로 한다.

- 공대원 입력 위에 접히는 칸 "명단 붙여넣기".
  1. 게임에서 파티창 캡처.
  2. ChatGPT·Claude 같은 AI 앱에 캡처와 "AI 요청 문구"(버튼으로 복사)를 보낸다.
  3. AI가 적어 준 명단을 붙여넣고 "명단 채우기".
- 읽는 규칙: 한 줄에 한 명. 줄 안에서 직업 이름 9개 중 하나를 찾고 나머지를 이름으로 본다(직업이 앞뒤 어디에 있어도 됨).
  번호(`1.`, `2)`, `3번`), 글머리표(`-`, `•`), "1파티"·"2파티" 머리줄, `1`·`2`만 있는 줄, 빈 줄은 건너뛴다.
  이름 끝의 `:`, `-`, `/`, `,`, 빈 괄호는 지운다. `[서버]`처럼 이름에 붙은 표시는 그대로 둔다.
- 채우기: 읽은 순서대로 1파티 1번부터 최대 10명. 깍두기와 직접 바꾼 자리는 자동으로 되돌린다.
  10명보다 적거나 많을 때, 직업을 못 읽은 사람이 있을 때 안내 문구를 보여준다.
